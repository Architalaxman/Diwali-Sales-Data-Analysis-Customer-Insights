Exploratory Data Analysis (EDA) of Diwali sales data to uncover customer purchasing behavior, product trends, and revenue insights using Python.
# 🎇 Diwali Sales Analysis

## 📌 Overview
This project performs Exploratory Data Analysis (EDA) on Diwali sales data to uncover key insights related to customer behavior, purchasing trends, and product performance.

The goal is to help businesses understand their customers better and optimize marketing strategies during festive seasons.

---

## 📂 Dataset
The dataset contains transaction-level data including:
- Customer demographics (Gender, Age, Marital Status)
- Product categories
- Purchase amount
- City and occupation details

---

## ⚙️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔍 Key Analysis Performed
- Data cleaning and preprocessing
- Handling missing values
- Exploratory Data Analysis (EDA)
- Visualization of sales trends
- Customer segmentation analysis

---

## 📊 Insights
- Identified top spending age groups
- Gender-based purchasing trends
- Most profitable product categories
- City-wise sales distribution
- Occupation-based customer insights

---

## 📈 Sample Visualizations
- Bar charts for category-wise sales
- Count plots for demographic distribution
- Heatmaps for correlation analysis
